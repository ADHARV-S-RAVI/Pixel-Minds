## 2. Automatic Expiry & 30-Day Cleanup Mechanism
Implemented in `supabase/migrations/20261104_auto_expiry_and_cleanup.sql` and mirrored in client-side lifecycle handling:

1. **Automatic Expiry**:
   - `public.expire_past_opportunities()` scans `public.opportunities` and transitions entries from `'published'` to `'expired'` once `deadline < now()`.
   - On the frontend (`src/pages.tsx`), any opportunity with `days <= 0` or passed deadline is dynamically excluded from public discovery feeds.
2. **30-Day Grace Period & Safe Archival**:
   - `public.cleanup_expired_opportunities()` transitions opportunities expired for $> 30$ days to `'archived'` status.
   - User submissions, Pixel transactions, and user activity records are completely preserved without foreign key cascade deletion.
3. **Anonymous RLS Fix**:
   - Executed `GRANT EXECUTE ON FUNCTION public.is_admin() TO anon;` to permanently eliminate PostgreSQL error code `42501` for anonymous visitors.
