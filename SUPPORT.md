# Support & Community Resources

Thank you for building with Pixel Minds! Here are the best ways to get help, ask questions, report bugs, and stay connected.

---

## 💡 Where to Ask Questions

- **Technical Discussion & Ideas**: Open a discussion on [GitHub Discussions](https://github.com/ADHARV-S-RAVI/Pixel-Minds/discussions) (or post in [GitHub Issues](https://github.com/ADHARV-S-RAVI/Pixel-Minds/issues) with the `question` label).
- **Architecture & Setup Help**: If you run into difficulties setting up your local Supabase database or running `npm run dev`, check the [README.md](README.md) troubleshooting section or open an issue using the Documentation Assistance template.

---

## 🐛 How to Report Bugs

If you encounter unexpected behavior, UI glitches, or broken functionality:
1. First, search [existing issues](https://github.com/ADHARV-S-RAVI/Pixel-Minds/issues) to see if the problem has already been reported.
2. If not, open a new issue using our [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.md).
3. Include your browser, operating system, console logs, and step-by-step reproduction instructions.

---

## 🚀 Requesting Features

Have an idea for a new filter, opportunity category, or reward mechanism?
- Use the [Feature Request Template](.github/ISSUE_TEMPLATE/feature_request.md) to explain the use case and expected benefit for builders.

---

## 📢 Where to Find Updates

- **GitHub Releases & Commits**: Watch or star the [Pixel-Minds repository](https://github.com/ADHARV-S-RAVI/Pixel-Minds) on GitHub to track ongoing updates.
- **Project Roadmap**: View current development priorities and upcoming milestones in [ROADMAP.md](ROADMAP.md).
- **Changelog**: Review releases and fixes in [CHANGELOG.md](CHANGELOG.md).
- **Direct Inquiries**: Contact the maintainers at **info.pixellminds@gmail.com**.
